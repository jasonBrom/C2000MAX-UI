# Liquid Glass 分支设计与实现

## 依据

- [Apple HIG · Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：Liquid Glass 用于导航和功能浮层；内容区域使用标准材质。文字较多的浮层优先 regular，照片背景可以使用 clear；保留减少透明度和增强对比度的体验。
- [Apple · Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)：以折射、边缘光和清楚的前后层级表达材质，而非给所有内容叠加模糊。
- [Apple HIG · Tab bars](https://developer.apple.com/design/human-interface-guidelines/tab-bars)、[Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)、[Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)：保持导航标签、明确选中态、按钮层级与键盘焦点。
- [Apple HIG · Motion](https://developer.apple.com/design/human-interface-guidelines/motion)、[Icons](https://developer.apple.com/design/human-interface-guidelines/icons)：统一符号视觉重量，以短促、可打断的交互反馈解释状态，并响应减少动态效果设置。
- [liquidGL 文档](https://github.com/naughtyduk/liquidGL)：使用独立 target / content、固定定位透镜、背景快照与 destroy 生命周期。基于 v3.0.0 和 MIT 许可证；上游提交 `88f681ab7035fd55b04f63edff1841e32c4199e9`，不分发其演示资产。本地增加 `snapshotBlur`、`animateSpecular`、`opacity` 可选参数及输入控件排除规则，修改已记入源码和 NOTICE。
- [liquidGL · Menu Bar 源示例](https://liquidgl.naughtyduk.com/demos/menu-bar.html)：参考其浅边缘透镜（refraction 0.016 / bevelDepth 0.014 / bevelWidth 0.071）及紧凑胶囊比例。本分支按实际文字背景与纹理预算调整，未照搬演示的 4 倍快照、强色散或第三方动画依赖。

## 材质重设计

移除先前深色 tint、深色 veil、描边和多重内阴影的重复叠加。GPU 就绪后边缘由真实透镜定义，CSS 仅保留一层轻量可读性填充；CSS 回退才使用细描边。导航和圆形按钮的折射 / 深度 / 边宽为 0.012 / 0.024 / 0.10，较大的面板为 0.008 / 0.018 / 0.075，低强度色散为 0.025。此实现是浏览器中的设计近似，不是 Apple 系统原生材质。

手机导航居中，最大宽度 440px、高度 72px，保留至少 44px 的触碰目标。选中胶囊本身是第二片真实透镜，以独立小快照折射导航图标和标签，保留原生 DOM 交互。经典主题使用中性明暗工作区；限定主题继承原有整套页面、卡片、文字、边框和强调色，玻璃填充随主题颜色适配。

选中透镜参考官方 Menu Bar：refraction 0.016、bevelDepth 0.014、bevelWidth 0.071、magnify 1.04、aberration 0.15、frost 0；其参数按底栏快照而非整页高度计算。外层底栏的可读性填充为浅色 2.5% / 深色 1.5%，前景区域保留轻量中性底色。选中项使用独立的 `.mobile-nav-items` 快照和底栏尺寸画布，文字预模糊为零，与页面背景场景分开堆叠。

| 主题 | 浅色页面 / 深色页面 | 配色方向 |
| --- | --- | --- |
| 经典银白 | #f2f4f8 / #14181e | 银白与蓝色 |
| 马年限定 | #faf4e5 / #211d16 | 金色羊皮纸与栗棕 |
| 中秋限定 | #f6f3e9 / #101c20 | 月色米白与深青绿 |
| 国庆限定 | #faf0eb / #211617 | 暖白、朱红与金色 |

管理页背景排除文字绘制并在上传前柔化 3px，避免背景与前景菜单、导航标签争夺阅读层级；壁纸登录页使用较清透的 2px 柔化。大段文字的抽屉和弹层有更强的可读性填充，底栏和小控件保持轻量。登录表单透出壁纸，输入字段单独建立稳定的对比度。

## 渲染与性能边界

首屏不再等待 idle callback 或固定 800ms。头部提前加载引擎，GPU 能力探测每种后端只执行一次；首张快照只画轻量背景场景，不等待设备大图，再补全真实内容快照。此时 CSS 材质始终可用。浏览器下载、着色器编译仍需要时间，不能保证冷启动零延迟。

路由在页脚导航启用前初始化，而非等待所有 defer 脚本完成后才接管；DOMContentLoaded 入口有幂等保护。专项测试会阻塞 defer 玻璃脚本，在此期间立即点导航并确认不重新载入顶层文档。内部 `data-navigation-instance` 与阶段标签可用来核对外层是否保留，不记录字段、凭据或设备身份数据。

`liquid-router.js` 保留外层导航、顶部按钮与画布；站内普通 GET 链接在同源内容 iframe 中打开原生 LuCI 页面。子文档保持独立的 L、轮询、表单、认证和弹窗，切页即移除旧内容文档；父文档停用原页轮询，顶部所有原生指示器转接到当前子文档，包含轮询和 `uci-changes` 配置数量及原生修改详情。地址栏使用 history，支持前进后退，未保存字段离开前确认；修饰键、新窗口、退出、下载和外链保留原生行为。外部主题 / 认证响应回到顶层页面，不绕过登录。初始视图的迟到渲染由隐藏空节点接收并立即清理。

内容文档按内容自动增高，外层文档负责正常页面滚动，避免手机浏览器将滚动锁在嵌套视口中。内页视口保持与外层同宽，通过外层内容区的左右内距排版，保证原生媒体查询一致，返回首页不会误入平板布局或丢失右侧列。子文档背景透明、不重复绘制页面背景；原生弹窗按外层可见区域定位和限高，弹窗开启时锁住外层滚动，弹窗表面独立接受触摸滚动。临近页面底部时暂时扩展 iframe 覆盖完整可见区域，关闭后恢复内容高度；原生弹窗遮罩覆盖外层底栏。移除子文档模态状态的固定 body 高度，防止可见内容被 iframe 底边裁切。玻璃快照仅采样本主题拥有的同源内容文档，排除输入和可编辑值，子文档的 2D 快照也限制约 200 万像素；滚动复用该快照，仅改变取样位置，内容变化时才重新绘制。子文档不另建导航 GPU 画布。手机 visualViewport 的 resize / scroll 与透镜几何同步；移除上游在每帧中强行将画布移到视口零点的逻辑，避免浏览器地址栏伸缩时背景透镜与前景标签分离。

登录页只取样 `#liquid-scene` 中的壁纸与暗角。管理页取样内容的颜色、几何与图片，排除文字绘制操作，以及所有玻璃功能层、页头、品牌、遮罩、输入、文本域、选择框和可编辑内容，防止滚动时出现旧文字和固定品牌的重影；输入值不进入纹理。库的可选 `snapshotText` 默认保留上游文本行为，管理页的页面背景设置为 false；仅底栏选中透镜另取样 `.mobile-nav-items`，包含其自身五个图标和标签，不含页面文字或字段。内容更新的快照请求以 500ms 合并，滚动使用已经上传的纹理，不逐帧重绘 DOM。

底栏背景和选中透镜各用一张底栏尺寸的局部画布，与前景标签共享同一个 fixed 祖先，移除跨固定合成层依赖 JS 追赶的定位方式。渲染目标只占底栏尺寸，手机地址栏伸缩时画布和标签由浏览器一起移动。顶部按钮和普通浮层共用基础固定容器中的画布，前景控件保留在上方 DOM 层。抽屉使用遮罩上方、抽屉前景下方的第二个固定容器；基础容器始终在遮罩下方，避免同一画布跨越前景与遮罩而覆盖文字。抽屉与外观 / 管理员菜单保留受八透镜总预算约束的准备池，展开时沿用已编译的画布与纹理，隐藏时不进行 GPU 绘制。页面隐藏、降级模式或离开时释放。登录卡片使用壁纸透镜；编辑弹窗使用可读性优先的常规材质。登录主操作使用居中标签与强调色填充，避免嵌套玻璃按钮的多重边缘。

常驻可见控件保留名额，再容纳临时浮层，总上限八个透镜。`inert` 仅禁止点击与焦点，不作为移除透镜的条件；隐藏、移出视口的面板仍会释放资源。这样打开外观菜单不会挤掉头像，打开抽屉也不会将底栏切换为 CSS 回退。背景仍按正常模态交互变暗和禁用。

管理页每个合成层的纹理预算约 200 万像素，底栏背景和选中胶囊有两个底栏尺寸的局部渲染目标；选中胶囊另用不超过 2 倍的微型文字快照，基础控件和展开的抽屉各有一个共享层，长表单降低快照分辨率；登录页最高 1.25 倍。透镜使用 specular，仅导航按压和拖拽期间启用 fluid；所有透镜关闭 tilt。上游的全局指针监听根据透镜边界计算位移，装饰代理保持 pointer-events:none，不拦截真实控件事件。局部 `opacity` 参数随真实面板的透明度同步，避免前景渐隐而装饰透镜突然消失。

本地 `snapshotBlur` 在纹理上传前缓存一次 Canvas 2D 模糊；shader 的 frost 设为 0，避免上游逐像素随机模糊的颗粒及每帧 16 次随机取样。clear 分支直接使用双线性采样，去除额外五点平均，避免低分辨率背景纹理使叠加的导航符号变糊，同时减少取样。共享渲染器按快照、定位容器、z-index 和模糊量分组，WebGPU / WebGL 都使用这张平滑纹理。若 Canvas filter 不可用，仍保留原始纹理与可读性遮罩。

底栏保留原生链接和按钮负责交互。参考上游 Menu Bar，选中胶囊的光学层在标签上方，通过零预模糊的局部快照轻微放大并折射自身文字；未选中项继续原生绘制。选中项使用 refraction .016、bevelDepth .014、bevelWidth .071、magnify 1.04 和适量色散，移除额外的 CSS 白色高光层。不同快照根的渲染器分别堆叠，避免页面的无文字透镜覆盖底栏的清晰文字快照。库中 SVG 内容缓存仍包含子图形透明度、颜色与变换，图标沿用同一份 sprite。

本地 `animateSpecular` 默认 true 保持上游行为，产品设为 false：保留成像中的高光，且 WebGPU / WebGL 都固定其光照相位，高光不再单独要求连续 GPU 重绘，也不会在其他内容重绘时跳到另一个时刻。按压、悬停、拖拽沿用同一弹簧状态，无首尾重启的常驻循环。滚动、快照更新、控件几何变化或指针 fluid 位移仍触发上游按需绘制。静止登录场景的 30 帧观察验证画布输出版本不再增长；这表示跳过 GPU 重绘，不表示上游的 rAF 几何检查也停止。

页面隐藏、浮层关闭、主题变化或壁纸更新时释放 / 重建透镜。低内存（浏览器报告 ≤2 GiB）、Save-Data、减少动态效果 / 透明度、强制颜色、GPU 不支持及脚本加载失败均保留可交互的 CSS 材质。无透明度支持时使用填充背景。

## 动效与图标

- 图标采用同一份 SVG sprite、24 单位网格、1.8 线宽和圆头圆角；导航选中使用配套的实心 / 加重版本。菜单分类保留原有 network / system / device / signal 语义色；悬停、焦点和展开时使用对应色系，暗色限定主题的系统图标提高亮度。密码显示使用 eye / eye-off，菜单开关和外观切换同步更新图形。外观切换复用现有 SVG，仅更新符号，保留其运动状态。图标是 Web SVG，不分发 SF Symbols 字体或资源。
- 普通控件按压与符号反馈采用按需运行的弹簧，重复输入只改变目标值或施加轻量冲量，当前位置和速度连续保留；松开或取消均从实际按压进度回弹。使用独立 scale，不覆盖原有 transform；静止后取消帧追踪并恢复内联样式。导航在按压和拖拽期间才启用 fluid，普通悬停不产生黏手位移。
- `liquid-nav.js` 单独管理导航透镜的横向位置、宽度和抬升弹簧。鼠标悬停只提供轻微底色，不移动选中胶囊，也不触发 fluid 跟随；键盘焦点仍可预览，按下抬升，水平移动超过 6px 开始拖拽，随速度适度拉伸，松开吸附最近项；原生点击 / 修饰键和 Enter 保留。拖拽预览使用独立 class，`aria-current` 只表示实际页面；真正导航在释放后执行，落回当前项不重新加载。方向键 / Home / End 移动焦点，Escape 取消。纵向手势保留页面滚动；指针取消与失去捕获均回到稳定状态。触屏隐式捕获从链接转移到导航时，不误判为取消。
- 退出 160ms、进入 240ms、抽屉 340ms，使用 `cubic-bezier(.2,.8,.2,1)`。外观 / 管理员菜单用内部 `C2000Motion.visibility(panel, opening, mutate)` 协调原有状态。快速反向切换从当前透明度和变换开始；退出时立即更新 aria、inert 与点击状态，视觉退出完成后清理。LuCI 直接移除的弹窗沿用自身销毁时机，新增弹窗有进入反馈；链接跳转和表单提交不为动画等待。
- 装饰性颜色 / 阴影过渡在首次交互后启用，避免首帧初始化触发额外过渡。减少动态效果会取消进行中的动画、压缩和回弹，状态立即落定；无常驻图标摆动和闪烁。
- 首页轮播直接更新展示状态，不模拟按钮点击，避免自动切换误关用户菜单；减少动态效果时暂停自动轮播，手动选页仍可使用。

## 验证

先按 README 渲染模板，再运行 `npm test` 和 `npm run test:browser`。光学专项检查必须等待 `data-glass-state="gpu"`，不能仅根据脚本加载或 canvas 存在判断成功。编辑弹窗与登录主按钮使用常规材质，按其可见性、可读性和操作状态验证。

覆盖 390 / 632 / 1350px 的浅深色登录与首页、共用画布、选中胶囊、抽屉和弹出菜单的开启 / 销毁、按住 / 松开、快速反向切换、退出阶段焦点与 inert、SVG 引用与密码图标、LuCI 弹窗、主题更新、原生登录 POST，以及六类回退。截图在首帧和相关过渡完成后生成。可用 `RECORD_MOTION=1 node tests/motion-browser.test.cjs` 生成本地演示视频。

`liquid-optics.test.cjs` 在实际页面导航下临时加入纯色 / 条纹测试背景，读取最终截图像素，而非依赖 canvas 存在或配置参数。自动后端和强制 WebGL2 路径均验证：背景换色会穿透到成像；开启 / 关闭折射的差异集中在窄边缘，中央不被扭曲；指针移动时产生非零 fluid 位移；宽手机底栏仍居中且满足触碰尺寸；静止登录页保留高光且不继续 GPU 重绘。测试背景仅存于测试页，不进入产品界面。

`glass-state.test.cjs` 覆盖常驻透镜身份在弹层 / inert 抽屉前后的保留、遮罩前后的正确层级、隐藏抽屉停止绘制、快速松开 / 重按及菜单反向切换时显示姿态连续、外观切换保留 SVG、八种主题外观及各分类图标的悬停颜色。

`navigation-glass.test.cjs` 检查透镜内实际显示的 SVG 像素、悬停保持选中位置、拖动拉伸、释放吸附 / 原生跳转、同项释放不刷新、抽屉状态、键盘、触摸取消 / 横向拖动 / 纵向滚动和减少动态效果。`RECORD_NAV=1 node tests/navigation-glass.test.cjs` 生成控制台交互及独立演示页的录屏。

`continuous-navigation.test.cjs` 阻塞设备图片来验证玻璃独立起步，使用真实触摸事件验证拖动无焦点圈、释放后画布与文档身份保持不变，并检查前进后退、未保存字段保留、迟到初始视图、子文档滚动 / 弹窗、快照预算和视口高度变化。触摸与鼠标拖拽不主动聚焦链接；指针模式移除导航焦点圈，键盘模式仍保留可见焦点。

未保存字段按实际用户输入 / 选择及其交互前基线判断。原生模组页自动填充下拉框不视为编辑；回归同时覆盖初始顶层与内页的自动选择，避免正常切页出现确认。子文档的原生弹窗会禁用外层导航，关闭后恢复；浮动底栏后仍有真实内容，内容末尾与操作按钮预留底栏空间。

本地 `/navigation` 使用同一份生产导航组件和 CSS 背景，不引入第三方演示图片。该开发演示拦截链接以连续选择五个位置；安装包不含开发服务，实际 LuCI 导航保留真实地址。

这些验证不能替代目标手机上的功耗、温升、Safari 兼容性和长期帧率测试；发布前仍需实机验证。

本地 Edge 短时调度采样记录保存在 `build/preview/liquid-profile.json`。requestAnimationFrame 间隔仅说明本机浏览器调度情况，不等于 GPU 实际完成时间或手机功耗。

常见资源数量：管理页手机可见五个透镜，准备池与可见项共不超过八个透镜；基础控件、局部底栏与准备好的抽屉共三个画布。抽屉隐藏时不绘制，打开时复用同一画布。桌面可见三个透镜，准备池内浮层共用基础画布。登录卡片和提交按钮共用一个画布，其余外观控件按定位容器复用。每次重新采样以本地 JSON 为准，不将桌面调度间隔作为手机性能结论。

`mobile-surface.test.cjs` 用真实触屏纵向手势验证切页后的外层滚动，验证底栏画布随固定祖先同步、渲染像素预算、透明内页、配置数量与原生详情转接、最后一行表单不被保存操作遮挡、滚动至底部后弹窗仍在可见区域、短会话弹窗无多余滚动条、桌面管理员胶囊及默认折叠菜单。菜单只保留一层分类展开，插件的更深层页面通过原生页签访问。

导航另有位于原生文字上方的透明反光盖层，随同一弹簧位置更新，保留触感与柔和边缘，不重新光栅化标签。紧凑按钮的折射 / 倒角也按页面长度归一化，避免长页面使圆形控件出现过大的边缘条纹。登录按钮共享登录卡片的渲染器，标签位于材质盖层上方，外观菜单使用独立的明暗可读性遮罩。

`glass-refinements.test.cjs` 比较首次与切页返回首页的右侧列位置，验证原生媒体查询宽度、QModem 标题 / 时间 / 纯文字页签的键盘与选中状态、已准备抽屉首帧、悬停不拉动选中项，以及实际截图中的高对比测试文字不渗入玻璃。另覆盖登录按钮与外观菜单。

设计依据：Apple [Materials](https://developer.apple.com/design/human-interface-guidelines/materials)、[Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons)、[Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/)；光学组合对照 [liquidGL Menu Bar](https://liquidgl.naughtyduk.com/demos/menu-bar.html)。编辑表单优先保证文字、触摸滚动和可达的操作区，导航保留轻量浮层、清晰边缘与弹性反馈。

`edit-surfaces.test.cjs` 以实际截图像素验证选中图标仍可见，并通过触摸事件验证长编辑表单滚动、最后字段可达、视口变化和底栏遮挡、取消后恢复页面滚动，同时检查品牌对齐、浅色菜单悬停与登录主操作。
